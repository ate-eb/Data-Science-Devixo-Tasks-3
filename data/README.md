# Dataset files

The complete raw dataset (10,012 rows), cleaned dataset (10,000 rows), and SQLite database are included in the downloadable project ZIP linked in the project handoff. This GitHub repository currently contains a small sample CSV for preview because the connected GitHub file workflow supports UTF-8 text files only and cannot transfer the binary database and report/image artifacts.

To make this repository fully self-contained, extract the project ZIP and copy its complete `data/raw/`, `data/processed/`, and `data/retail_sales.db` files into the matching folders here.
